How placement works
  • Best fit — the account with the smallest remaining budget that still fits, with a stable name tiebreak. A replacement excludes the account that currently holds the file and needs a free slot and enough bytes elsewhere.
  • Reservations — in-flight jobs reserve bytes and slots before B2 is called, so concurrent clients cannot overbook an account.
  • Restart truth — at boot, every account's latest versions rebuild the cache and accounting. Duplicate names across accounts abort startup until b2router-reconcile --apply resolves them; an interrupted upsert can leave that short-lived duplicate.
