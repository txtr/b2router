How placement works

Best fit

A new file goes to the account with the smallest remaining byte budget that still fits, with a stable account-name tiebreak. Same-account replacement can reuse its old file slot.

Reservations

In-flight jobs reserve bytes and slots before B2 is called, so concurrent clients cannot overbook an account. Reservations are released in a finally block.

Restart truth

At boot, every account's latest versions rebuild the cache and accounting. Duplicate names across accounts abort startup until b2router-reconcile --apply removes the stale copy.
